# Maze

Implements the `PuzzleGame` interface from `src/shell/game.ts`.

Arrives in milestone 2 (see `../../../BRIEF.md`, "Build plan"): recursive
backtracker generator with tests, canvas rendering, swipe/arrow-key sliding
movement, win detection. Must never import `platform.ts` or call any `ytgame`
API; ads, timer and streak live in the shell.
